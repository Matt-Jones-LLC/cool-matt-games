About 0 tokens.

Token counts here are estimates: about four characters of English per token. Real tokenizers differ by model and by language, and code and non-English text usually cost more. For an exact figure, use the token counter that comes with the model you're using.

Everything is sent every time

A model doesn't remember the system prompt from the last turn. The whole prompt, every tool definition and every earlier message is sent again with each new message, so fixed overhead is paid on every turn.

Leave room for the answer

The reply comes out of the same window. If the input fills it, the model has nowhere to write. Reserve the longest reply you expect, and more if the model thinks before it answers.

What to do when it fills

Three options, usually combined: drop the oldest turns, replace them with a summary, or fetch documents only when a question needs them. This planner shows when you'll have to choose.
